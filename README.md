# What is it?

Sacados is an inventory system made for Unity, with the following characteristics:

- Compatibility (configured per container)
  - Singleplayer
  - Multiplayer
    - FishNet networking solution
- Samples
  - Fixed Size (fixed slots count)
  - Flexible Size (shrinkable and growable slots)

However, you must keep in mind that Sacados is mostly an Inventory system in a Kit.
Samples are here to give advices on how to setup the system for some gameplay.
But for more complex, or unique behaviours, you must change quite a lot of things to fit the gameplay style you are looking for.
